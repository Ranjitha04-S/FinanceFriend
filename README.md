# Daily Collection (Next.js + Supabase)

1. Create a free project at supabase.com, open SQL Editor, run `supabase.sql`.
2. Copy `.env.local.example` to `.env.local` and paste your project URL + anon key (Settings > API).
3. `npm install && npm run dev` (open on phone via your LAN IP, or deploy free on Vercel and add the same two env vars).
4. On the phone, open the Vercel URL in Chrome and use "Add to Home screen".

Voice: tap Speak and say "Ravi 500" or "Ravi Kumar 1200 rupees". The last number is the amount, the words before it are the name.
Voice needs HTTPS (Vercel gives this) and Chrome/Edge/Safari.
